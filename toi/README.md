# Той чакыруулары (Django)

Онлайн той чакырууларын түзүп сатуу үчүн сайт. Ар бир чакырууга өз шилтемеси берилет.

- `/owner/` — сиздин панелиңиз: чакыруу түзүү, аттар, дата, тойкана, **фонго сүрөт**, **эки жаштын сүрөттөрү (12ге чейин)**, **музыка (mp3)**.
- `/i/<код>/` — конокторго жибериле турган чакыруу (конверт, анимациялар, таймер, календарь, программа, 2GIS, «Келесизби?»).
- `/i/<код>/guests/<жашыруун код>/` — той ээси үчүн келе тургандардын тизмеси. Бул шилтемени той ээсине гана бериңиз.

## Компьютерде иштетүү (Windows)

```
cd toi
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Андан кийин http://127.0.0.1:8000/owner/ дарегин ачып, «Жаңы чакыруу» баскычын басыңыз.

Тесттер: `python manage.py test inv`

## Эскертүүлөр

- Музыка: кардар берген же эркин лицензиядагы ырды гана жүктөңүз. Файл 20 МБдан, сүрөт 10 МБдан ашпашы керек.
- Телефондор музыканы «мөөрдү» баскандан кийин гана ойнотот.
- Серверге коюуда `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`, `DJANGO_ALLOWED_HOSTS=<домен>` чөйрө өзгөрмөлөрүн коюңуз жана `/media/` менен `/static/` папкаларын веб-серверден таратыңыз (PythonAnywhere: Web → Static files).
